WARREN BASTERFIELD TECHNICAL PORTFOLIO — WEBSITE PACKAGE

This is a static website. No build tools or server-side code are required.

UPLOAD:
1. Upload the contents of this folder to the website root/public_html/www directory.
2. Keep all HTML files, styles.css and script.js in the same folder.
3. index.html is the homepage.

FILES:
- index.html                 Main portfolio homepage
- ai.html                    Applied AI & Computer Vision section
- case-study-01.html ...    12 case-study pages
- styles.css                 Site styling / Apex-aligned palette
- script.js                  Case-study search on the homepage

BRANDING:
The site is intentionally designed as a sibling to Apex Core Integration:
- dark technical background
- light neutral text
- restrained teal accent
- clean, minimal, engineering-focused layout
- Apex Core Integration link retained in the navigation
